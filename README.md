## 🩺 간호과정 도우미 (`NursingHelper/`)
주관적·객관적 자료를 넣으면 간호진단을 추천하고 간호과정의 큰 틀을 만들어 줍니다.

- 형식 3가지: **제출 양식**(사정 / 간호계획 및 수행 / 합리적 근거 / 간호평가, A4·표지) · **B4 워크북**(간호과정 별책 순서) · 기본 형식
- NANDA-I 2024–2026 간호진단 131개 (별책 부록 6·8 기준 진단명·영역·과·쪽수), 진단 찾기, 목록에 없는 진단 직접 입력
- 아동 간호진단(욕창·성장발달·빨기-삼킴·고빌리루빈혈증·모유수유 등), 농가진이면 피부·감염·안위 진단에 농가진 간호 추가
- Word(.doc) 저장, 제미나이 / ChatGPT / Claude로 다듬기

## 📖 간호 공부방 (베타, `NursingStudy/`)
간호학 **개념 · 술기**를 자세한 설명과 수행 순서로 공부하고, **국가고시 형식 문제**로 스스로 점검합니다.

- 과목별 주제: 설명 · 꼭 외울 값 · 간호중재 · 주의할 점 · 관련 영상(유튜브 검색으로 연결)
- 술기 순서: 단계마다 이유(근거), 핵심 단계 표시, **핵심 단계 가리고 외워 보기**
- 문제 풀기(과목·문제 수 선택) · 오답 노트 · 즐겨찾기 · 전체 검색
- 🏥 **가상 EMR 실습**: 가상 환자의 V/S 흐름표·그래프, 처방, 검사, 수술기록지·경과기록, 간호기록, I/O를 **시간 순서대로** 보며 다음 증상과 우선 간호를 판단 (환자·보호자 말은 기기 음성 + 자막). 사례: 복강경 담낭절제술 후 출혈, 두부 외상 IICP, DKA 치료 — 모두 가상 환자·교육용 가상 처방
- 베타: 주제 12개부터 시작해서 계속 추가해요. 넣고 싶은 내용이나 틀린 내용은 앱 안 버튼(→ Issues)으로 알려 주세요.
- 내용은 교과서 일반 지식을 바탕으로 새로 쓴 글이에요. 실습·시험은 학교 교재와 기관 지침을 따르세요.
- 내용 추가: `NursingStudy/web/content/<id>.json` 한 파일 = 한 주제 (형식: `content/SCHEMA.md`) → `python3 NursingStudy/build.py`

## 📝 HWP 편집기 (`HwpEditor/`)
한글 문서(**.hwp · .hwpx**)를 열어 보고 고치는 앱이에요. 인터넷 없이 기기 안에서만 열어요.

- 열기: .hwp(한글 5.0 이후) · .hwpx · .txt · .html — 글자 모양, 문단 모양, 표(합친 셀·배경·테두리), 그림, 머리말·꼬리말, 쪽 번호, 각주·미주, 하이퍼링크, 글상자, 수식(분수·루트·첨자 모양으로), 문서에 정한 문단 번호 모양(가. 1) ① Ⅰ 등)·글머리표, 문단 테두리·배경
- 고치기: 글자 모양(Alt+L) · 문단 모양(Alt+T) · 스타일(바탕글·본문·개요 1~7, Ctrl+1~9) · 문단 번호·글머리표 · 표 만들기(Ctrl+N,T)·줄/칸 추가·지우기·셀 블록(F5)·합치기(M)·나누기(S)·테두리/배경(L) · 찾아 바꾸기(Ctrl+H) · 문자표(Ctrl+F10) · 편집 용지(F7) · 쪽 나누기(Ctrl+Enter) · 삽입/수정(Insert) · 되돌리기
- 메뉴(파일·편집·보기·입력·서식·쪽·표·검토·도구) 배치와 **단축키는 한글 2022와 같게** 맞췄어요(도구 → 단축키 목록, F1). 아이콘·그림은 새로 그렸어요.
- 쪽 화면: 실제 용지 크기로 쪽을 나눠 보여 주고(쪽 윤곽), 표 칸 안의 글도 줄 단위로 다음 쪽에 넘겨요. 폭 맞춤·쪽 맞춤·두 손가락 확대, 많이 줄이면 **쪽 모아보기**(쪽을 누르면 그 쪽으로)
- 한글과 같게 보이기: 보기 모드에선 한글 파일에 저장된 줄 바꿈 위치를 그대로 쓰고, 각주는 쪽 아래에, 가운데·오른쪽 정렬된 그림·표, 표 칸 여백, 장평(글자 폭)을 반영해요. 안드로이드엔 명조 글꼴(나눔명조)을 넣었어요
- 저장: **.hwpx**(한글 2014 이상에서 열림) · PDF · 인쇄 · HTML · TXT · 카톡 등으로 보내기. .hwp로 연 문서도 .hwpx로 저장돼요.
- 📱 안드로이드: 카톡·내 파일에서 연 문서는 "문서 여는 중" 화면을 거쳐 보기 모드(뷰어)로 열려요. [편집하기]를 누르면 고칠 수 있고, [다음부터 바로 편집]을 누르면 그다음부턴 바로 편집 모드로 열려요. 첫 화면 아래에 버전이 보여요. 카톡·내 파일에서 hwp를 누르고 **HWP 편집기**를 고르면 바로 열려요. 연 .hwpx 파일에 그대로 덮어 저장돼요.
- 🖥️ **삼성 덱스(DeX)**: 창 크기 조절, 키보드 단축키, 마우스 오른쪽 클릭 메뉴, Ctrl+휠 확대
