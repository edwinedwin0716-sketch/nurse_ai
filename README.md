# 디톡스 런처 (Detox Launcher)

안드로이드 16(API 36) 기반 **디지털 디톡스용 홈 화면(런처) 앱**입니다.
휴대폰을 덜, 그리고 더 의식적으로 쓰도록 돕습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 미니멀 홈 화면 | 아이콘 없이 글자만. 시계·날짜·꼭 필요한 앱(최대 8개)만 표시 |
| 오늘의 화면 시간 | 홈에 오늘 사용 시간, 잠금 해제 횟수, '참은 횟수', 하루 목표 진행 막대 표시 |
| 잠깐 멈춤 | '방해 앱'을 열면 숨쉬기 애니메이션과 함께 N초(5~60초) 기다려야 열림 |
| 앱별 하루 한도 | 15/30/60/90분 한도. 넘으면 그날은 런처에서 열 수 없음 |
| 집중 모드 | 25분~4시간 동안 방해 앱 차단 (+ 허용 시 방해 금지 모드 자동 켜기/끄기) |
| 앱 숨기기 | 앱 목록에서 유혹되는 앱을 숨김 (검색하면 보임) |
| 흑백 화면 안내 | 회색조 설정으로 바로 이동 |
| 오늘 많이 쓴 앱 | 설정 화면에서 사용 시간 순위 확인 |

## 사용법

- 홈에서 **위로 밀기** → 모든 앱
- 홈에서 **아래로 밀기** → 알림창
- 홈 **길게 누르기** → 설정
- **시계 누르기** → 알람
- 앱 **길게 누르기** → 홈에 추가 / 방해 앱 지정 / 하루 한도 / 숨기기 / 앱 정보

## 설치 방법 (휴대폰)

1. 이 저장소의 **Releases** 페이지에서 최신 `DetoxLauncher.apk` 를 휴대폰으로 받습니다.
   (또는 **Actions → Build APK → Artifacts**)
2. 설치 시 "출처를 알 수 없는 앱 허용"을 켭니다.
3. 앱을 열면 나오는 안내에 따라
   - 기본 홈 앱으로 설정
   - 사용 정보 접근 허용
   - (선택) 방해 금지 제어 허용
4. 새 빌드로 업데이트할 때 "서명이 다르다"는 오류가 나면 기존 앱을 지우고 설치하세요.

## 직접 빌드

```bash
gradle assembleRelease   # Gradle 8.14.3
# 결과: app/build/outputs/apk/release/app-release.apk
```

Android Studio 로 이 폴더를 열어도 됩니다. (JDK 17, Android SDK 36 필요)

## 구조

```
app/src/main/java/com/detox/launcher/
  MainActivity.kt      런처 화면 (홈 버튼, 뒤로가기 처리)
  LauncherState.kt     화면 상태, 앱 열기 규칙(멈춤·한도·집중 모드)
  Prefs.kt             설정 저장
  AppRepository.kt     설치된 앱 목록 / 실행
  UsageHelper.kt       오늘 사용 시간·잠금 해제 횟수 계산
  ui/                  홈, 앱 목록, 멈춤 화면, 설정 화면
```
