# 간호 공부방 내용 형식 (content/<id>.json, 한 파일 = 한 주제)

```json
{
  "id": "iicp",                       // 영문 소문자·하이픈, 파일 이름과 같게
  "subject": "성인간호학",             // 기본간호학 | 성인간호학 | 아동간호학 | 모성간호학 | 정신간호학 | 지역사회간호학 | 기본간호술기
  "kind": "개념",                     // 개념 | 술기
  "title": "두개내압 상승 (IICP)",
  "en": "Increased intracranial pressure",
  "tags": ["신경계", "응급"],
  "summary": "2~3문장 요약",
  "numbers": [{"label": "정상 ICP", "value": "5~15 mmHg"}],      // 꼭 외울 정상치·기준값 (없으면 [])
  "sections": [                                                   // 자세한 설명
    {"h": "원인", "items": ["..."]},                               // items = 글머리표 목록
    {"h": "병태생리", "text": "문단 글"}                            // text = 문단 (items와 둘 중 하나)
  ],
  "steps": [                                                      // 술기만: 수행 순서 (개념이면 [])
    {"do": "손위생을 한다", "why": "교차 감염 예방", "key": true}  // key = 시험·실습에서 특히 중요한 단계
  ],
  "cautions": ["임상에서 주의할 점"],
  "nursing": ["간호중재 (개념 주제)"],
  "videos": [{"label": "ICP 상승 간호", "query": "두개내압 상승 간호"}],   // 유튜브 검색어 (주소를 지어내지 않는다)
  "quiz": [
    {"q": "문제", "options": ["①", "②", "③", "④", "⑤"], "answer": 2, "explain": "해설 (왜 정답이고 왜 나머지가 틀린지)"}
  ],
  "check": ["사람이 교재와 맞춰 볼 것 (앱에는 안 보임)"]
}
```
- answer는 0부터 센다 (첫 보기 = 0).
- 문제는 국가고시 형식 5지선다, 주제마다 5문제 이상.
- 숫자·약물 용량은 교과서에서 널리 쓰는 표준값만. 기관마다 다르면 "기관 지침에 따라".
