# 가상 EMR 사례 형식 (content/cases/<id>.json, 한 파일 = 가상 환자 한 명)

모든 시간은 "D0 14:30" 형식 (D0 = 입원·수술 당일, D1 = 다음 날, D-1 = 전날). 학생은 stage를 하나씩 넘기고,
그 stage 시각까지의 기록만 보인다. 환자·병원·의료진은 모두 가상이다 (실존 인물·병원 이름 금지).


- 숫자는 생리적으로 앞뒤가 맞아야 한다 (예: 출혈 → HR↑, BP↓, 소변↓, Hb↓ 순서와 시간 간격이 그럴듯하게).

- stage 4~7개, 판단 질문(ask)은 사례 전체에서 5~8개, 5지선다, answer는 0부터.
