간호 공부방 (Windows 10/11) 0.1 베타
==================================
간호학 개념·술기 설명을 읽고, 국가고시 형식 문제로 스스로 점검하는 앱이에요.
인터넷 없이 이 PC 안에서 열려요. (관련 영상 버튼만 유튜브로 연결돼요)

■ 설치
1. 압축 파일을 우클릭 → 모두 압축 풀기
2. 간호공부방.exe 더블클릭
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]
3. 앱 창이 열리고, 바탕화면과 시작 메뉴에 "간호 공부방" 아이콘이 생겨요.
   설치가 끝나면 "내려받은 설치 폴더와 예전 zip을 지울까요?"라고 물어봐요. [예]를 누르면 정리돼요.

■ 쓰는 법
- 과목 → 주제를 고르면 설명 · 술기 순서 · 문제를 볼 수 있어요.
- 술기 순서에서 "핵심 단계 가리고 외워 보기"로 스스로 떠올려 보세요.
- 문제 풀기: 과목과 문제 수를 고르면 섞어서 나와요. 틀린 문제는 오답 노트에 모여요.
- ☆ 를 누르면 즐겨찾기에 모여요.

■ 알아 두세요
- 베타 버전이에요. 내용은 계속 늘어나요. 새 버전 zip의 exe를 한 번 실행하면 바뀌어요. (오답 노트·즐겨찾기는 그대로)
- 교과서 일반 내용을 바탕으로 정리했어요. 실습·시험은 학교 교재와 기관 지침을 따르세요.
- 틀린 내용·추가 요청은 앱 아래 "이런 내용도 넣어 주세요" 버튼으로 알려 주세요.
- 지우기: 바탕화면 아이콘 삭제 + %LOCALAPPDATA%\NursingStudy 폴더 삭제
