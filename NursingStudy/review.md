검토 기준: 기본간호학·성인·아동·모성간호학 표준 교재 내용, 널리 쓰이는 지침
확인 결과: `python3 NursingStudy/build.py` → **주제 12개 · 문제 76개** 정상 빌드

## 전체 검사 결과

- **정답 번호**: 76문제 모두 정답 번호(0부터 셈)가 실제로 맞는 보기를 가리키고, 정답이 하나뿐인지 확인했습니다. 해설 안의 보기 번호(①~⑤)는 동맥혈가스분석 3번 문제에만 있으며, ①=첫 번째 보기 순서와 맞습니다.
- **주소(URL)**: 어느 파일에도 없습니다. 영상은 모두 `{label, query}`(검색어) 형식입니다.
- **보기 개수**: 모두 5지선다이고 같은 보기가 두 번 나오는 문제는 없습니다.
- **주제 사이 숫자 맞추기**: SpO₂ 95~100%(활력징후·산소요법·동맥혈가스분석), MAP 계산식(두개내압·쇼크), 모세혈관 재충혈 2초(쇼크·아동 탈수), 소변량 0.5 mL/kg/시간(쇼크·아동 청소년), 벡 3징후(두개내압 문제 해설·쇼크)가 서로 같습니다. 서로 달랐던 흡인 시간만 고쳤습니다(아래 참고).
- **저작권**: 교재 문장을 길게 그대로 옮긴 부분은 없고, 모두 쉬운 말로 다시 쓴 문장입니다.

## 파일별로 고친 내용

### iicp.json (두개내압 상승)
- 흡인 시간이 흡인 주제(1회 10~15초 이내)와 달라 보였습니다(10초 이내). 그래서 "일반 원칙(10~15초 이내) 안에서도 가능한 한 짧게(흔히 10초 이내)"로 고쳐 두 주제를 맞췄습니다.
- "저장성 수액(예: 5% 포도당액)" → "몸 안에서 저장성으로 작용하는 수액(예: 5% 포도당액)"으로 고쳤습니다. 5% 포도당액은 병에 든 상태로는 등장성이지만, 포도당이 대사되면 몸 안에서 저장성으로 작용합니다. 수액 종류는 처방에 따른다는 말도 넣었습니다.
- 제목에 영어만 있던 "Monro-Kellie 가설"을 "먼로-켈리(Monro-Kellie) 가설"로 바꿨습니다.
- 퀴즈 6문제는 모두 맞아서 고치지 않았습니다.

### suction.json (기관내 흡인)
- 고친 것 없음. 1회 10~15초, 흡인 전후 100% 산소, 넣을 때 음압 걸지 않기, 기관내 → 구강 순서가 모두 맞고 퀴즈도 정확합니다.

### vital-signs.json (활력징후 측정)
- 술기 제목은 "활력징후 측정"인데 순서(steps)에는 혈압만 있었습니다. 그래서 **체온 → 맥박 → 호흡(+산소포화도)** 측정 단계 3개를 혈압 단계 앞에 넣었습니다(각 단계에 이유와 핵심 표시 포함).
- 확인 목록에 두 가지를 더했습니다: 측정 순서가 평가항목과 같은지, 촉진법 뒤 몇 mmHg 더 부풀리는지(20~30 mmHg).
- 파일 줄바꿈 형식이 정리되었지만 내용은 위의 추가 말고는 그대로입니다.

### oxygen.json (산소요법)
- 비재호흡 마스크 저장주머니가 "약 2/3 이상 부풀어 있게"라는 숫자는 교재마다 달라서 뺐습니다. 대신 "완전히 쭈그러지지 않도록"이라고 적었습니다.
- COPD 저산소 자극 설명 앞에 "교재에서는 흔히 다음과 같이 설명한다"를 붙였습니다. 최근에는 환기-관류 불균형 같은 다른 기전도 함께 설명하기 때문입니다.
- 위 두 가지를 확인 목록에 넣었습니다.

### abga.json (동맥혈가스분석)
- 앨런 검사의 "양성·음성"이라는 말은 교재마다 반대 뜻으로 씁니다(정상을 양성이라 하는 교재도, 음성이라 하는 교재도 있음). 그래서 헷갈리지 않게 "손 색이 돌아오지 않으면(측부 순환 부족) 채혈하지 않는다", "정해진 시간 안에 돌아오면 측부 순환이 충분하다"처럼 결과를 말로 풀어 썼습니다.
- 퀴즈 6문제의 해석(비보상·부분보상·완전보상)을 모두 다시 계산했고 맞습니다.

### foley.json (유치도뇨)
- "비우세손은 끝날 때까지 떼지 않는다"를 "도뇨관이 방광에 들어가 소변이 나올 때까지 떼지 않는다"로 고쳤습니다(술기 단계와 1번 문제 해설 둘 다). 소변이 나오면 그 손으로 도뇨관을 잡고 풍선을 부풀리기 때문입니다.

### shock.json, dm-acute.json, im-injection.json, transfusion.json, peds-dehydration.json, newborn-assessment.json
- 고친 것 없음. 숫자(MAP 65, 패혈성 쇼크 30 mL/kg, 15-15 규칙, DKA·HHS 기준, 근육주사 부위·주사량, 수혈 4시간·15분 관찰·생리식염수만 사용, 탈수 정도·유형, Apgar·비타민 K·황달 기준)와 퀴즈 정답·해설을 모두 확인했고, 맞거나 이미 "처방·기관 지침에 따라"로 적혀 있습니다.
- 신생아 1번 문제의 Apgar 점수(2+1+1+1+1 = 6점)도 다시 계산해 맞는 것을 확인했습니다.

## 교재와 꼭 맞춰 볼 항목 (모든 주제 모음)

각 파일의 `check` 항목을 모은 것입니다. 교재와 다르면 교재 숫자로 바꾸면 됩니다.

**숫자·기준값**
1. 두개내압: 정상 ICP 5~15, 치료 기준 20 mmHg 이상 / 정상 CPP 70~100, 최소 유지 기준(50~60 또는 60~70) / 두개 안 내용물 비율(80·10·10%) / 침상머리 30도(15~30도) / 과환기 기준 / GCS 중증도 구분
2. 흡인: 성인 흡인 압력(80~120, 100~150, 150 미만 등) / 미리 산소 주는 시간(30~60초, 1~2분)과 방법 / 카테터 넣는 깊이 / 1회 10~15초, 반복 횟수 / 카테터 굵기(내경 1/2 이하) / 생리식염수 기관 안 주입을 하지 않는다는 입장 / **흡인 시간(일반 10~15초, IICP는 더 짧게)**
3. 활력징후: 구강 체온 정상 범위와 부위별 차이(0.5℃) / 호흡 12~20회(16~20회) / 혈압 정상 기준(<120 그리고 <80) / 커프 폭 40%·길이 80%, 커프 아래 끝 위치(2~3 cm) / 직장 체온계 삽입 깊이 / 구강 체온 전 기다리는 시간(15~30분) / 다시 잴 때 기다리는 시간(1~2분) / **촉진법 뒤 부풀리는 높이(20~30 mmHg)** / **술기 측정 순서**
4. 산소요법: 기구별 유량·FiO₂(비강 캐뉼라, 단순 마스크, 벤추리, 비재호흡) / 가습 시작 기준(4 L/분 이상 등) / 산소 독성 기준(FiO₂ 50% 이상, 24~48시간) / COPD 목표 SpO₂ 88~92% / **저장주머니 부풀어 있는 정도** / **COPD CO₂ 저류 기전 설명 방식**
5. 동맥혈가스분석: 정상치(SaO₂ 95~100% 또는 95~98%) / **앨런 검사 판정 시간과 양성·음성 용어의 뜻** / 채혈 후 압박 시간(5분, 항응고제 10분 이상) / 산소 바꾼 뒤 채혈까지 기다리는 시간(20~30분) / 검체 얼음 운반 여부 / 완전 보상 때 pH 7.40으로 원래 장애 구분하는 방법
6. 쇼크: 단계 구분(4단계 / 3단계) / MAP 65, 소변량 0.5 mL/kg/시간 / 패혈성 쇼크 30 mL/kg·젖산 4 mmol/L / 신경성 쇼크 손상 수준(T6 이상) / 변형 트렌델렌버그 자세 / 노르에피네프린 일혈 때 펜톨아민
7. 당뇨 급성 합병증: 저혈당 70·54 mg/dL 기준 / 15-15 규칙 음식 예(주스 120 mL 등) / DKA 기준(혈당 250 초과, pH 7.30 미만, HCO₃⁻ 18 미만 — 최신 지침은 혈당 기준을 낮추기도 함) / HHS 기준(600 초과, 삼투압 320 초과) / 포도당 수액 넣는 시점(200 또는 250) / 혈당을 잴 수 없을 때 저혈당으로 보고 처치하는 원칙 / 아픈 날 혈당 측정 간격(3~4시간)
8. 유치도뇨: 삽입 길이(여성 5~7.5 cm, 남성 17~22.5 cm 또는 18~20 cm) / 미리 풍선 부풀려 보기를 평가항목에서 요구하는지 / 도뇨관 굵기 / 방광 팽만 때 처음 빼는 양 제한 / 소변주머니 연결 시점 / 회음부 소독 순서와 솜 개수
9. 근육주사: 흡인 여부(전통 교재 5~10초 흡인 vs 백신은 흡인 불필요) / 부위별 최대 주사량 / 바늘 굵기·길이 / 바늘 바꾸기·필터 바늘 / Z-track 당기는 거리·기다리는 시간 / 투약 원칙(5 Right 또는 더 넓힌 원칙) / 알코올 소독 범위
10. 수혈: 정맥 카테터 굵기(18~20 G) / 출고 뒤 시작 시간(30분 이내) / 처음 15분 주입 속도 / 활력징후 재는 시점과 간격 / 2인 확인을 누가 하는지와 확인 항목 / 알레르기 반응 뒤 수혈을 다시 할지 / 반응 때 혈액 백 반납·검체 채취 절차 / 제제별 주입 시간
11. 아동 탈수: 정도별 체중 감소율 / 정도별 모세혈관 재충혈 시간 / 등장성 Na 130~150 / 나이별 정상 소변량 / ORS 양(50·100 mL/kg, 4시간) / 중증 볼루스 20 mL/kg / 고장성 교정 기간(약 48시간)
12. 신생아 초기 사정: 심박수(110~160 또는 120~160) / 혈압 / 비타민 K 용량·시기 / 안연고 약과 시기 / 제대 소독 여부 / 생리적 황달이 가장 심한 시기·병적 황달 기준 / Apgar 다시 재는 기준(5분 7점 미만이면 5분마다 20분까지)
