Spotlight for Windows 1.0
=========================
Mac의 Spotlight와 똑같은 모양의 검색창이에요.
Shift 키를 두 번 빠르게 누르면 화면 위쪽에 검색창이 열립니다.

■ 설치
1. 압축을 풉니다. (압축 파일 우클릭 → 모두 압축 풀기)
2. Spotlight.exe 를 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]
3. "설치했어요!" 창이 뜨면 끝. 압축 푼 폴더는 지워도 됩니다.
   (프로그램은 %LOCALAPPDATA%\MySpotlight 에 복사되고, Windows를 켤 때 자동으로 실행돼요)

■ 사용법
- Shift 두 번 : 검색창 열기 / 닫기
- 글자 입력 : 앱 · 문서 · 폴더 · Windows 설정 · MySpace 런처에 등록한 항목을 찾아요
    · 초성 검색도 돼요 : ㅋㅋㅇㅌ → 카카오톡,  ㄱㅎ → 간호…
    · "와이파이", "블루투스", "밝기", "프로그램 삭제" 같은 설정도 바로 열려요
    · 계산기 : 12*3+4, (5+5)/2, 2^10, 15% 를 입력하면 바로 계산 → Enter 로 결과 복사
    · 맨 아래 Google / 네이버 검색
- ↑ ↓ : 선택 이동
- Enter : 열기
- Ctrl + Enter : 파일 위치(탐색기) 열기
- Esc : 글자 지우기 → 한 번 더 누르면 닫기
- 다른 곳을 클릭해도 닫혀요
- 자주 여는 항목은 점점 위로 올라와요

■ 설정 (작업 표시줄 오른쪽 ^ 안의 Spotlight 아이콘 우클릭)
- 단축키 : Shift 두 번 / Alt + Space / Ctrl + Shift + Space
- 테마 : 자동(Windows 설정 따라감) / 라이트 / 다크
- Windows 시작 시 실행 켜기 · 끄기
- 목록 새로 고침 : 새로 설치한 앱이 안 보일 때
- 종료

■ 참고
- 키보드의 Fn 키는 Windows가 신호를 받을 수 없어서 Shift 두 번으로 만들었어요.
- Shift를 길게 누르거나, Shift+글자(대문자 입력)는 무시되니까 타자 칠 때 실수로 열리지 않아요.
- 새 버전으로 바꿀 때 : 아이콘 우클릭 → 종료 후, 새 Spotlight.exe 실행
- 지우기 : 아이콘 우클릭 → "Windows 시작 시 실행" 끄기 → 종료 → %LOCALAPPDATA%\MySpotlight 폴더 삭제
- 인터넷으로 아무것도 보내지 않아요. (웹 검색을 고를 때만 브라우저가 열려요)
