MySpace 런처 for Mac 1.0

어떤 파일을 받나요?
- Apple 실리콘(M1·M2·M3·M4 등) Mac:  MySpace-mac-AppleSilicon.tar.xz
- 인텔 Mac:                          MySpace-mac-Intel.tar.xz
  (확인: 화면 왼쪽 위  → 이 Mac에 관하여 → '칩'이 Apple M… 이면 Apple 실리콘)

설치
1. 받은 .tar.xz 파일을 더블클릭하면 풀리면서 MySpace.app 이 나와요.
   (안 풀리면 터미널에서:  tar -xf ~/Downloads/MySpace-mac-AppleSilicon.tar.xz -C ~/Downloads)
2. MySpace.app 을 '응용 프로그램(Applications)' 폴더로 끌어다 놓으세요.
3. 처음 열 때 (Apple 인증서가 없는 직접 만든 앱이라 한 번만 필요)
   ① MySpace.app 을 더블클릭 → "확인할 수 없습니다" 창이 뜨면 [완료]
   ② 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "MySpace"이(가) 차단됨 옆 [그래도 열기] → 암호 입력
   ③ 다시 MySpace.app 을 열면 실행돼요. 이후로는 그냥 열려요.
   (안 되면 터미널에서:  xattr -dr com.apple.quarantine /Applications/MySpace.app  후 다시 열기)

사용
- 화면 아래 가운데(Dock 위)에 반투명 창으로 떠요. 메뉴 막대 오른쪽 위 ▦ 아이콘으로도 열고 닫을 수 있어요.
- ⌥(Option) + Space : 어디서나 열기/숨기기  (⋯ 메뉴 → 열기/숨기기 단축키에서 바꿀 수 있어요)
- 왼쪽 위 버튼: 빨강 = 종료, 노랑 = 숨기기, 초록 = 항상 위
- 검색창(⌘F)에 입력 → Enter 로 첫 번째 항목 바로 실행, Esc 로 지우기/숨기기
- 투명도: 오른쪽 위 슬라이더, ⌘ + 스크롤, ⋯ → 투명도
- 라이트/다크: ☾ / ☀︎ 버튼
- 추가: Finder에서 앱·파일·폴더를 창에 끌어 놓기, 또는 ＋ → 앱/파일/폴더/웹사이트/카테고리 추가
- 타일 우클릭: 열기, Finder에서 보기, 즐겨찾기 고정, 이름 변경, 카테고리 이동, 목록에서 제거
- ⋯ 메뉴: 자동 추가, 항상 위, 로그인 시 자동 실행, Dock 아이콘 표시, 창 크기(2·3·4줄), 투명도, 단축키

자동 추가 (켜져 있으면 15초마다)

- 그 뒤: 새로 설치한 앱, 데스크탑·다운로드에 새로 생긴 파일, 새 Steam 게임
