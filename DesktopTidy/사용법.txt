바탕화면 정리 1.0

하는 일
바탕화면에 흩어진 파일을 '바탕화면\정리됨' 폴더 안의 종류별 폴더로 옮겨요.
  문서 / 이미지 / 영상·음악 / 압축파일 / 설치파일 / 기타

안전 장치
- 삭제는 절대 하지 않아요. 옮기기만 해요.
- 옮기기 전에 무엇을 옮길지 목록으로 보여 주고, 확인을 받은 뒤 옮겨요.
- '되돌리기'를 누르면 지난번에 옮긴 파일을 원래 자리로 돌려놔요.
- 그대로 두는 것: 바로가기 아이콘(.lnk, .url), 폴더, 숨김·시스템 파일, 열려 있는 Office 임시 파일(~$…)
- 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 '이름 (2)'처럼 저장해요.
- 사용 중인 파일은 건너뛰고 알려 줘요.
- MySpace 런처에 등록된 파일을 옮기면 런처 타일의 경로도 같이 바꿔요.
  (런처가 켜져 있으면 잠깐 닫아도 되는지 묻고, 끝나면 다시 열어요. 바꾸기 전 목록은 items.json.before-tidy로 백업)

사용 방법
1. DesktopTidy.exe를 더블클릭 (파란 경고창이 뜨면 '추가 정보' → '실행')
2. 목록을 확인하고 '정리하기'
3. 원래대로 돌리고 싶으면 다시 실행해서 '되돌리기'

설치는 필요 없어요. Windows 10/11 · 관리자 권한 필요 없음.
