MySpace Launcher 1.3.1 — 친구 배포용

1.3.1 바뀐 점
- 예전 버전 실행 파일은 자동으로 지워요.
- 설치가 끝나면 "내려받은 설치 폴더와 예전 zip을 지울까요?"라고 물어봐요. [예]를 누르면 정리돼서 같은 파일이 여러 번 쌓이지 않아요.

1.3 새 기능
- 웹사이트 타일에 실제 로고 표시 (ChatGPT, Gemini 등 · 처음 한 번 내려받아 저장)
- 더 선명한 64px 아이콘, Microsoft Store 앱 아이콘도 표시
- 얇은 Windows 11 스타일 스크롤바
- 창 크기 선택: ⋯ 메뉴 → 창 크기 → 작게(2줄) / 보통(3줄) / 크게(4줄)
- 새 투명도 아이콘(◐)
- 단축키 Ctrl+Shift+Space: 어디서나 런처 열기/숨기기
- 검색 후 Enter: 첫 번째 항목 바로 실행
- 우클릭 메뉴에 '열기', '파일 위치 열기' 추가
- 알림 영역 아이콘 한 번 클릭으로 열기/숨기기
- 아이콘 캐시로 검색·탭 전환이 더 빨라짐

1.2 새 기능
- 애플(macOS) 스타일 새 디자인: 신호등 창 버튼, 둥근 검색창, 세그먼트 탭, 런치패드 아이콘
- 투명도 조절: 오른쪽 위 슬라이더(30~100%), Ctrl + 마우스 휠, ⋯ 메뉴 → 투명도
- 라이트 / 다크 모드 전환 (해·달 버튼)
- 더 큰 고화질 아이콘, Windows 11 둥근 모서리, 새 앱 아이콘
- 단축키: Ctrl+F 검색, Esc 검색 지우기/숨기기
- 투명도·테마 설정은 자동 저장됩니다

지원 환경
Windows 10/11. Windows 기본 .NET Framework 4.x 및 Windows PowerShell 5.1 사용.
Python, Node.js, 개발 도구와 관리자 권한이 필요 없습니다.
회사·학교 PC에서는 PowerShell 실행 정책으로 실행이 제한될 수 있습니다.

설치
1. 받은 MySpaceLauncher-1.1.zip을 압축 해제합니다.
2. MySpaceSetup.exe를 실행합니다.
   이전 버전이 실행 중이면 자동으로 닫고, 예전 실행 파일·로그·바로가기를 지운 뒤 새로 설치합니다.
   등록한 항목(items.json)은 유지되며, 설치 전에 items.backup.json으로 백업합니다.
3. 바탕화면의 MySpace 런처를 더블클릭합니다.
설치 위치: %LOCALAPPDATA%\MySpaceLauncher
처음 설치할 때 자동 실행이나 Windows 시작 프로그램 등록은 하지 않습니다.

설치하지 않고 실행
MySpaceLauncher.exe를 더블클릭해도 됩니다. EXE 하나에 실행 코드가 포함되어 있습니다.
설정과 실행에 필요한 파일은 사용자 계정의 위 설치 위치에 생성됩니다.
이 배포본에는 제작자의 파일 경로, 문서, 등록 목록, 백업, 계정 정보가 없습니다.
친구 PC의 바탕화면 바로가기와 설치된 AI/메신저를 첫 실행 때 등록합니다.
문서·다운로드 폴더 링크와 ChatGPT/Gemini/Higgsfield 웹 링크도 기본으로 표시합니다.
AI 서비스는 각 서비스의 계정으로 로그인해야 하며, 런처가 구독을 제공하지 않습니다.

사용
- 창은 주 화면의 중앙 하단, 작업표시줄 바로 위에 표시됩니다.
- 즐겨찾기 / AI / 메신저 / 업무 / 게임 / 문서 / 도구 탭으로 분류합니다.
- 전체 탭은 모든 등록 항목을 보여줍니다.
- 타일을 클릭하면 해당 파일·앱·웹사이트가 열립니다.
- + 버튼 또는 파일 끌어놓기로 등록합니다.
- 타일 우클릭: 즐겨찾기 고정/해제, 이름 변경, 카테고리 이동, 목록에서 제거.
- 검색창에서 이름이나 경로를 검색합니다.
- 왼쪽 위 신호등 버튼
  · 빨강: 종료합니다. EXE나 바탕화면 바로가기로 다시 엽니다.
  · 노랑: 알림 영역으로 숨깁니다. 아이콘 더블클릭 또는 우클릭 → 런처 열기.
  · 초록: 항상 위 켜기/끄기 (다른 창 위에도 런처를 표시)
- + 버튼: 파일 추가 / 폴더 추가 / 카테고리 추가
- ⋯ 버튼: 자동 추가, 항상 위, 다크 모드, 투명도, 창 크기, 숨기기, 종료
- Ctrl+Shift+Space: 어디서나 런처 열기/숨기기

자동 추가
켜져 있으면 실행 중 15초마다 확인합니다.
바탕화면·다운로드의 새 파일, 시작 메뉴의 새 바로가기, 설치된 Steam 게임을 추가합니다.
첫 실행 당시 존재하던 일반 파일은 한꺼번에 추가하지 않습니다. 필요한 파일은 수동 등록하세요.
실행을 종료한 동안 새로 생긴 파일은 다음 실행 때 추가합니다.
자동 추가를 끈 동안 생긴 항목은 다시 켜면 추가될 수 있습니다.
메신저와 AI 바로가기는 이름에 따라 분류하며 우클릭으로 수정할 수 있습니다.
다른 게임 플랫폼은 바로가기가 생기면 감지합니다. 바로가기가 없으면 수동 등록하세요.
하위 폴더의 문서나 시스템 전체를 검색하지 않습니다.
목록에서 제거한 항목은 자동으로 다시 등록되지 않습니다. 수동 추가는 가능합니다.
바탕화면에 학기중 학습 폴더가 있으면 폴더 링크만 등록하며 내부를 변경하지 않습니다.
런처는 원본 파일을 이동하거나 삭제하지 않습니다.

백업·업데이트·제거
설정 백업: 런처 종료 후 %LOCALAPPDATA%\MySpaceLauncher\items.json을 복사합니다.
복원: 종료한 상태에서 같은 위치에 되돌립니다. 등록 경로는 해당 PC에 실제로 있어야 합니다.
업데이트: 새 MySpaceSetup.exe를 실행합니다. 실행 중인 런처는 자동으로 닫히고, 등록 목록은 유지됩니다.
제거: 런처 종료 후 바탕화면 MySpace 런처 바로가기와 위 설치 폴더를 삭제합니다.
등록한 원본 파일과 프로그램은 그대로 남습니다.

문제 해결
실행 실패 기록: %LOCALAPPDATA%\MySpaceLauncher\runtime.log
단독 EXE는 코드 서명되지 않은 자체 제작 프로그램입니다.
Windows 보안 경고가 나오면 파일을 보낸 사람과 출처를 확인하세요.
백신을 끄거나 회사·학교의 실행 제한을 우회하지 마세요.
타일 실행 실패: 원본 파일이 이동되었는지 확인하고 새 경로를 등록하세요.
