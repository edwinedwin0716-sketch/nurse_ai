원시섬 실험 서버 (내 컴퓨터에서 돌리기) 0.1
==========================================
공룡이 사는 섬에서 살아남는 3인칭 3D 게임이에요. 이 폴더로 내 컴퓨터가 게임 서버가 되고,
같은 와이파이의 휴대폰·친구 컴퓨터가 함께 접속해요. (실험용 · 인터넷 서버 아님)

■ 처음 한 번
1. https://nodejs.org 에서 Node.js LTS를 설치해요. (계속 [다음]만 누르면 돼요)

■ 켜기
1. "서버 켜기.bat" 더블클릭
   - 파란 창 "Windows의 PC 보호" → [추가 정보] → [실행]
   - 방화벽 창이 뜨면 [허용] (같은 와이파이 기기가 들어오려면 필요해요)
2. 브라우저가 열리면 "실험 서버에 들어가기" → 이름 입력 → 시작하기
3. 검은 창에 찍힌 http://192.168.x.x:8080 주소를 휴대폰 크롬/사파리에 치면 같은 섬에서 만나요
4. 끄려면 검은 창을 닫아요. 저장은 saves 폴더에 이름별로 남아요.

■ 조작
- PC: W A S D 이동 · 마우스 둘러보기 · Shift 달리기 · Space 점프 · 클릭 치기 · E 줍기/먹기/굽기 · Tab 가방 · 1~5 손에 들기
- 휴대폰: 왼쪽 화면 누르고 움직이기 · 오른쪽 화면 밀어 둘러보기 · 오른쪽 아래 버튼 (점프·줍기·달리기·치기)

■ 해 볼 것
나뭇가지·돌멩이 줍기 → 가방에서 돌도끼 → 나무·바위 캐기 → 모닥불 놓고 고기 굽기 → 돌창으로 사냥 → 천막
밤에는 발톱이가 더 멀리서 달려와요. 횃불을 들면 주변이 밝아요.
