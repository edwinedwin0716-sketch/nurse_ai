원시섬 실험 서버 (내 컴퓨터에서 돌리기) 0.2
==========================================
0.2: 그래픽 새로 (그림자·풀·물결·하늘), 버려진 캠프에서 시작, 짓기(울타리·움막·가마·건조대·우물·망루),
     새 공룡 큰이빨·판등이·뿔방패, 망루 오르기, 조준(오른쪽 클릭 / 🎯), 그래픽 품질(높음·보통·낮음)

공룡이 사는 섬에서 살아남는 3인칭 3D 게임이에요. 이 폴더로 내 컴퓨터가 게임 서버가 되고,
같은 와이파이의 휴대폰·친구 컴퓨터가 함께 접속해요. (실험용 · 인터넷 서버 아님)

■ 처음 한 번
1. https://nodejs.org 에서 Node.js LTS를 설치해요. (계속 [다음]만 누르면 돼요)

■ 켜기
1. "서버 켜기.bat" 더블클릭
   - 파란 창 "Windows의 PC 보호" → [추가 정보] → [실행]
   - 방화벽 창이 뜨면 [허용] (같은 와이파이 기기가 들어오려면 필요해요)
2. 브라우저가 열리면 "실험 서버에 들어가기" → 이름 입력 → 시작하기
3. 검은 창에 찍힌 http://192.168.x.x:8080 주소를 휴대폰 크롬/사파리에 치면 같은 섬에서 만나요
4. 끄려면 검은 창을 닫아요. 저장은 saves 폴더에 이름별로 남아요.

■ 조작
- PC: W A S D 이동 · 마우스 둘러보기 · Shift 달리기 · Space 점프 · 클릭 치기 · 오른쪽 클릭 조준 · E 줍기/먹기/굽기/오르기 · Tab 가방(만들기·짓기) · 1~5 손에 들기 · 짓는 중 R 돌리기
- 휴대폰: 왼쪽 화면 누르고 움직이기 · 오른쪽 화면 밀어 둘러보기 · 오른쪽 아래 버튼 (점프·줍기·달리기·조준·치기)
- 화면이 끊기면 처음 화면의 "🎨 그래픽"을 눌러 보통·낮음으로 바꿔요

■ 해 볼 것
나뭇가지·돌멩이 줍기 → 가방에서 돌도끼 → 나무·바위 캐기 → 캠프 모닥불·가마에서 고기 굽기 → 돌창으로 사냥 → 가방 '짓기'로 울타리·움막
밤에는 발톱이가 더 멀리서 달려와요. 큰이빨을 만나면 캠프나 망루로 피하세요. 우물에서 물을 마시면 기력이 차요.
