# review-in-3.json 검토 보고서

검토한 진단 36개. 수정 61건 (키워드 정리 39건, 본문·목표 22건). en/domain/cls/page는 바꾸지 않았다.
확인: JSON 로드 OK, 모든 keywords가 Python `re`(IGNORECASE)와 JS `new RegExp(...,'gi')`에서 컴파일 OK, 목록 길이(short 2, diag 3, ther 4–5, edu 2) 유지.
※ 앱은 keywords를 대소문자 무시(`'i'`)로 쓰기 때문에 영어 짧은 단어가 다른 단어 안에서 걸리는 문제가 여러 개 있었다.

## 가장 심각했던 문제
1. **키워드가 엉뚱한 기록에서 걸림 (흔한 단어 안에 포함됨)**
   - 영적 고뇌: `기도`가 airway(기도 유지·기도 흡인)에, `신부`가 신부전에, `pray`가 spray에, `종교`가 입원기록의 "종교: 무교"에 걸림
   - 비효과적 부정: `부정`이 부정맥·부정적에 걸림, `괜찮다고`가 통증 질문에 "괜찮다고 함"에 걸림
   - 분만 통증: `진통`이 진통제에, `labor`가 laboratory에, `NST`가 against에 걸림
   - 절박성 요실금 `urge`가 surgery에, 배뇨 장애 `UTI`가 solution에, 심장조직관류 `stent`가 consistent에, 두개내압 `ICH`가 which에, 조직 손상 `burn`이 heartburn에, `stage [2-4]`가 암 병기에, 신체 기동성 `THR`이 three에 걸림
   - 신생아 저체온 `체온 ?3[0-6]`가 정상 체온 36.8에 걸림 → 36.5 미만만 걸리도록 고침
2. **흡인의 위험 – 경구 식사 자세 오류**: "좌위 또는 침상머리 30~45°"로 되어 있어 입으로 먹는 식사도 30°로 해도 되는 것처럼 읽힘 → 경구 섭취는 똑바로 앉은 자세, 30~45°는 경관 영양에만 적용하도록 나눔.
3. **심장조직관류 감소의 위험 – 니트로글리세린 119 신고 시점**: "최대 3회, 호전 없으면 119"는 3회(15분)를 다 쓴 뒤 신고하는 것으로 오해될 수 있음 → "첫 투여 후 5분이 지나도 호전되지 않으면 즉시 119"(현행 지침).

## 사람이 확인하면 좋은 것
- **자살예방 상담전화 109**: 2024년 1월부터 통합 운영되는 번호로 알고 있어 남겨 두었다. 배포 전에 한 번 더 확인 권장. 1577-0199는 확실하지 않아 뺐다.
- **두개내압 ICP 목표 20mmHg**: 국내 교과서 기준으로 두었다(최신 BTF 지침은 22mmHg). 학교 교재 기준에 맞춰 확인.
- **활동 지속성 감소의 중단 기준**(맥박 +20회/분, SpO2 90% 미만)과 **활동 후 3분 내 회복**: 흔히 쓰는 기준이지만 교재마다 조금씩 다르다(예: COPD는 SpO2 88%).
- **흡인의 위험 – 위 잔류량 확인**: 최근에는 일상적인 측정을 줄이는 추세라 "병원 지침에 따라"를 붙였다.
- **신생아 고빌리루빈혈증 광선요법 중 2~4시간마다 체온, 2~3시간마다 체위 변경**: 기관마다 간격이 다를 수 있다.
- **알레르기 – 항생제 피부반응검사**: 국내에서는 일상적인 시행을 권장하지 않는 쪽으로 바뀌어 "병원 지침에 따라"를 그대로 두었다.
- **손상의 위험 – "필요시 침대 난간을 올린다"**: 혼돈 환자에게 4면 난간을 모두 올리면 억제대에 해당하고, 넘어 내려오다 다칠 수 있다는 의견이 있다. 교재 표현을 그대로 두었으니 확인 권장.
- 키워드를 많이 줄여서 일부 진단(신생아 저체온, 아동 발달 지연, 활동 지속성 감소)은 전보다 덜 자동 추천된다. 의도한 변화지만, 실제 예시 기록으로 추천 결과를 시험해 보길 권장.
