# adapted.json 변경 기록 (19개)

검증 결과: JSON 로드 정상, 키 19개(adapt 14개 + new 5개, 입력 순서 그대로), 모든 필드 있음, short 2 / diag 3 / ther 4–5 / edu 2, priority·page는 정수, keywords는 Python `re`(re.I)와 JS `new RegExp(k,'gi')` 둘 다에서 컴파일됨, 샘플 문장("보호자 동반, 기도 확보, 진통제 투여, 부정맥 없음, 유산균 복용, heartburn, laboratory, surgery, 체온 36.8℃, BMI 22")과 맞는 키워드 없음. en/domain/cls/page는 입력 값을 그대로 썼다.

## 새로 쓴 5개

- **신체 기동성 장애의 위험** (priority 5): 근력(MMT)·관절가동범위(ROM)·보행 사정, 방해 요인, 부동 합병증(욕창, 구축, DVT 징후), 능동/수동 ROM, 단계적 조기 이상, 활동 전 통증 조절, 2시간마다 체위 변경, 물리치료 협력. 키워드는 실제 진단 "신체 기동성 장애"(편마비, 골절 등)와 겹치지 않게 침상안정/bed rest/부동/근력 저하 위주로 정함.
- **체액량 과다의 위험** (priority 5): 매일 체중과 I/O, 부종·수포음·경정맥 팽대, 전해질·BUN·Cr, 수액 속도를 정확히 유지, 수분·나트륨 제한, 갈증에 구강 간호, 처방된 이뇨제를 쓸 때 K 확인. 체중 보고 기준은 숫자 없이 "갑자기 늘면"으로 씀. 키워드는 실제 진단 "체액량 과다"(부종, 폐부종 등)의 증상 대신 위험 요인(수분 제한, 저염식, CKD, 심부전, 투석 등)으로 정함.
- **고체온의 위험** (priority 5): 체온조절 실패 기준(고온 환경, 과도한 보온, 심한 활동, 탈수, 약물). 해열제를 쓰지 않고 물리적 냉각(시원한 곳, 옷 느슨하게, 미온수, 선풍기)을 함. 왜 해열제 효과가 적은지 근거를 적고, 떨림 관리, 의식 변화 시 응급 보고를 넣음. 영아·노인 과보온 주의. 키워드에 "체온"이나 "발열"은 넣지 않음.
- **변실금** (priority 4): 배변 일지, 원인(범람성 실금 포함), 실금 관련 피부염 예방, 배변 훈련, 화장실 접근성, 대변 굳기 조절, 존엄성, 골반저근(케겔) 운동.
- **과도한 외로움** (priority 6): 외로움 정도 사정(척도 이름은 쓰지 않음), 원인이 된 분리 상황, 우울과 자해 생각 선별 및 보고, 연락 돕기, 친숙한 물건, 전문가 연계.

## 사람이 확인할 것

1. **priority 기준**: 위험 진단은 5, 자기관리(건강관리 영역) 진단은 7로 맞춤. 그래서 *자율적 반사장애의 위험*이 2→5로, *비효과적 오심 자기관리*가 3→7로 내려갔다. 앱에서 순위를 매길 때 자율적 반사장애(생명 위협)를 더 높게 두려면 2로 되돌릴 것.
2. **숫자를 남긴 곳**(교과서 표준이지만 확인 권장): 수술 후 6~8시간 내 자연 배뇨, 체중 감량 주 0.5~1kg, 저혈당 15g–15분 규칙, 자율적 반사장애 수축기 혈압 20~40mmHg 상승과 2~5분 간격 측정, 2시간마다 체위 변경, Zarit 부담 척도(예시로만).
3. **영아 신경발달조직 손상**: 공식 정의가 "1세 미만 발달 이정표 지연"이라서 예전의 NICU 행동 조직화 내용을 일부 남겼다(스트레스 신호, 둥지 만들기). 과제가 신생아 중환자실 중심인지 영아 발달 전반인지 확인할 것. 키워드 "milestone", "hypotoni"는 영어 기록에서 다른 뜻으로 쓰일 수 있다.
4. **키워드가 겹침**: "피로"는 *돌봄제공 부담감 과다*의 기록("보호자 피로")에도 맞을 수 있다. "척수 손상"은 *침상 기동성 장애*와 겹친다. "심부전/투석"은 *체액량 과다*와 *체액량 과다의 위험* 둘 다에 있다(앱이 둘 다 추천해도 된다면 문제없음).
5. 자율적 반사장애의 domain/cls(9. 대처/스트레스 내성 / 3. 신경행동학적 스트레스)와 page는 입력 값을 그대로 썼다.
