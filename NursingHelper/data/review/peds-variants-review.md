# peds.json · variants.json 검토 기록

## 고친 것
### peds.json (아동 진단 17개)
- **진단명·영문·영역·과·쪽수는 그대로** 두었다 (peds-in.json과 같은지 확인함).
- **keywords(자동 추천 단어)를 16개 진단에서 좁혔다.** 고치기 전에는 성인 기록 54문장 중 46번이 아동 진단에 잘못 걸렸다. 지금은 0번이다. 예:
  - "nasal cannula 2L", "수면무호흡으로 CPAP" → 신생아 욕창 위험이 뜸 → 미숙아·NICU·신생아와 같이 쓰였을 때만 뜨게 함
  - "BT 36.2℃", "수술 후 저체온" → 신생아 체온감소 위험이 뜸 → 체온 숫자는 빼고, 신생아·미숙아와 같이 쓰였을 때나 보육기·방사보온기·캥거루 돌봄일 때만 뜨게 함
  - "T-bil 3.2, 황달", "ABO 부적합 수혈" → 신생아 고빌리루빈혈증 위험이 뜸 → 신생아/생리적/모유 황달, 생후·일령, 광선요법, TcB, 태변 지연, 두혈종으로 바꿈
  - "인공호흡기 weaning", "PEEP", "기관 삽관" → 소아 호흡기 제거가 뜸(성인용 진단이 따로 있음) → 소아·환아·영아·신생아·PICU·NICU가 같이 쓰였을 때만
  - "식욕 부진", "섭취량 감소", "체중 감소", "식사 거부", "삼킴 곤란·사레", "OG tube", "근긴장도 저하", "hypotonic saline", "걷지 못함", "장기 입원", "간병 부담", "직장 복귀", "죄책감", "사회적 지지 부족", "다이어트·야식·폭식·탄산음료", "binge drinking", "조산 위험 산모" → 모두 아동·영아·부모·청소년 같은 말과 함께 쓰일 때만 뜨게 함
  - "모유수유를 **적**극 권장" → "모유 … 적"에 걸리던 것 고침(부족·적게·적음 등으로만)
  - "목을 못 가눔"이 원래 식에서 안 걸리던 것(가누 ≠ 가눔) 고침
- 아동 기록 예문 20개는 모두 맞는 진단에 걸리는 것을 확인했다. 모든 식은 Python re(re.I)와 JS RegExp(gi, i)에서 컴파일된다.
- 계획·근거 문장, 원인(cause), 목표, 우선순위는 교과서 내용과 어긋나는 것이 없어 바꾸지 않았다. 원인은 모두 증상·자료형(약한 빨기 반사, 호흡근의 피로, 산모와 영아의 분리 등)이고 의학적 진단명(폐렴, 농가진, 고빌리루빈혈증, 뇌성마비 등)은 없다.
- build_templates.py의 check()로 17개 모두 통과(short 2개, diag 2–4, ther 3–6, edu 1–3, priority 1–7, short에 {자리표시} 없음). plan/why/목표는 "~다."로 끝나고 reason은 마침표 없음.

### variants.json (농가진)
- `when` 식은 성인 기록·"가피 형성된 수술 부위"·"꿀물 섭취" 등에 걸리지 않아 그대로 두었다.
- 피부 통합성 장애 치료적 계획 2: 앞 항목에서 이미 세척하므로 "처방에 따라 병변을 세척한 후 국소 항생제…" → "세척한 병변에 처방된 국소 항생제 연고를…"로 고침(중복 제거).
- "필요시" → "필요 시"(다른 파일과 띄어쓰기 맞춤).
- 약 이름·용량·등원 날짜 같은 숫자는 원래 없었다.

## 사람이 교재로 꼭 확인할 것
1. 숫자: 신생아 정상 액와 체온 36.5~37.5℃, 수유 하루 8~12회(목표 "하루 8회 이상"), "생후 24시간 이내 황달은 즉시 보고" — 교재 기준과 같은지.
2. 우선순위: 빨기-삼킴 = 1(기도·흡인), 신생아 체온감소의 위험 = 2(위험 진단인데 높게 둠), 욕창 4 / 욕창 위험 5, 고빌리루빈혈증 위험 5, 모유수유 중단 4.
3. 도구 이름: Braden Q(아동 욕창), K-DST 6개 영역(대근육·소근육·인지·언어·사회성·자조). 신생아 욕창 위험 도구는 이름 없이 씀.
4. 모유수유 진단의 주어 "산모는", 수유 자세 이름(풋볼 자세 등)이 교재 용어와 같은지.
5. 농가진: 균 이름 표기(황색포도알균/A군 사슬알균), 합병증(봉와직염, 사슬알균 감염 후 급성 사구체신염), 가피 불려서 제거, 병변을 거즈로 느슨하게 덮기, 경구 항생제 대상("넓거나 수포성"), 영아 면장갑 — 교재에 있는지.
6. 추천 단어를 좁혔기 때문에, 아동 기록인데 "아동/환아/영아/신생아" 같은 말 없이 "식욕 부진", "BT 36.0℃"처럼만 쓰면 해당 아동 진단이 자동 추천되지 않을 수 있다(진단 목록에서 직접 고르면 됨). 실제 실습 기록 몇 개로 추천이 잘 되는지 한 번 확인.
