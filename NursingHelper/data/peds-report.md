# peds.json 작성 기록 (아동간호학 17개 진단)

- 입력: `peds-in.json` 17개 → 출력: `peds.json` 17개 (입력 순서 그대로, en/domain/cls/page 그대로 복사)
- 확인한 것: JSON 로드, 모든 필드 있음, 개수(short 2 / diag 3 / ther 4–5 / edu 2), priority·page 정수, reason 끝 마침표 없음, short에 {자리표시자} 없음, plan/why "~다."로 끝남, keywords가 Python re(re.I)·JS(new RegExp gi)에서 컴파일됨, 무관 예시 문장에 하나도 걸리지 않음

## 사람이 확인하면 좋은 것
1. **우선순위 판단**
   - `영아의 비효과적 빨기-삼킴 반응` = 1 (수유 중 흡인·무호흡 위험 = 기도/호흡으로 판단). 교재가 영양(4)으로 본다면 바꾸기.
   - `아동 욕창` = 4 (실제 피부 손상 = 기타 생리적), `신생아 욕창의 위험` = 5.
   - `모유수유 중단` = 4, `비효과적 모유수유의 위험` = 5, `신생아 체온감소의 위험` = 2 (위험 진단이지만 체온 영역).
2. **숫자가 들어간 곳** (표준 지침 값만 사용)
   - 신생아 정상 액와 체온 36.5~37.5℃ (WHO 기준), keywords의 36.0~36.4℃ 이하 = 저체온.
   - 신생아 수유 하루 8~12회(고빌리루빈혈증 short: "하루 8회 이상").
   - "생후 24시간 이내 황달은 즉시 보고" (병적 황달 기준).
   - 성장 keywords의 3·5 백분위수는 검색용일 뿐, 계획 문장에는 기준값을 넣지 않음.
3. **도구 이름**: Braden Q 척도(아동 욕창), 한국 영유아 발달선별검사(K-DST, 영역: 대근육·소근육·인지·언어·사회성·자조). 신생아 피부 위험 도구는 이름 없이 "신생아용 피부 위험 사정 도구"로만 씀.
4. **모유수유 진단의 주어**: "산모는"으로 씀. 교재 표현(어머니/수유부 등)에 맞춰 바꿔도 됨.
5. **원인(cause)** 은 모두 증상·자료형 표현(의학적 진단명 아님): 예) "약한 빨기 반사", "호흡근의 피로", "산모와 영아의 분리", "불충분한 수유 섭취와 태변 배출 지연". 실습 대상자 자료에 맞게 바꿔 쓰는 기본값임.
6. **모유 보관 기간·유축 횟수**: 숫자를 넣지 않고 "기관 지침에 따라", "일정한 간격으로 규칙적으로"로 씀 (기관마다 기준이 달라서).
7. **keywords 겹침**: `\bCPAP\b`·미숙아·NICU 등이 욕창 위험·운동발달 위험 진단에 함께 걸릴 수 있음 (같은 신생아 기록이면 두 진단이 같이 추천됨). "황달"은 신생아 기록에 흔하지만 해당 진단의 핵심어라 유지.
