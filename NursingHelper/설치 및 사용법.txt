간호과정 도우미 1.7.1

1.7.1 바뀐 점
- Windows 보안(백신)이 1.7을 'Trojan:Win32/Sabsik.FL.A!ml'로 잘못 잡는 문제를 고쳤어요.
  예전 Windows판은 숨긴 PowerShell 창으로 화면을 띄웠는데, 이 방식이 악성코드와 비슷해 보여 인공지능 검사(!ml)에 걸렸어요.
  이제는 휴대폰·웹판과 같은 화면을 Edge 앱 창으로 열어요(간호 공부방·HWP 편집기와 같은 방식). 기능은 같아요.
- 예전 판에 저장된 설정(표지 정보, 제미나이 키)은 옮겨지지 않아요. 한 번만 다시 넣어 주세요.

1.7 새 기능
- 한글(.hwpx)로 저장: 저장 창에서 '한글 문서 - 제출 양식 (*.hwpx)'을 고르세요. 한글 2014 이상에서 열려요.
- 제출 양식을 학교 간호과정 보고서 모양으로 바꿨어요: 진단마다 '▪간호과정' 표(회색 제목 줄 · 사정(자료수집) · 간호계획 및 수행 · 합리적 근거 · 간호평가),
  맑은 고딕 9pt, 주관적/객관적 자료 · 목표(단기/장기) · 계획(진단적/치료적/교육적) · 수행 · 근거 · 평가 순서. Word로 저장해도 같은 모양이에요.
- 표지: 학기·과목, 제목, 실습장소, 담당교수, 학번, 성명, 학교·학과를 넣을 수 있어요.
- 주황색 글자는 직접 채울 곳이에요(진단 정의, 수행 결과, 참고문헌, 평가 결과).

1.6 새 기능
- 아동 간호진단 17개 추가 (모두 131개, 별책 부록 6·8 기준): 아동 욕창, 신생아 고빌리루빈혈증의 위험, 영아의 비효과적 빨기-삼킴 반응, 지연된 아동발달, 모유수유 중단 등
- 농가진: 자료에 '농가진'이나 '벌꿀색 가피'가 있으면 피부 통합성 장애·감염의 위험·손상된 신체적 안위에 농가진 간호가 더해져요. (원인은 "농가진과 관련된"이 아니라 긁음·병변 같은 대상자 자료로 쓰세요)
- 설치가 끝나면 내려받은 설치 폴더와 예전 zip을 지울지 물어봐요. 예전 버전 실행 파일은 자동으로 지워요.

무엇을 하나요?
주관적·객관적 자료를 넣으면 간호과정 보고서의 큰 틀을 자동으로 만들어 줍니다.
■ 사정(주관적/객관적 자료) → ■ 진단 → ■ 계획(장기·단기목표, 진단적·치료적·교육적 계획 + 이론적 근거)
→ ■ 중재(계획을 '~하였다'로 바꾸고 날짜·시간 칸 생성) → ■ 평가(달성 / 부분적 달성 / 달성 못함)

설치
1. 압축 파일을 우클릭 → 모두 압축 풀기
2. NursingHelper.exe를 더블클릭합니다. (파란 경고창이 뜨면 '추가 정보' → '실행')
3. 앱 창이 열리고, 바탕화면과 시작 메뉴에 '간호과정 도우미' 아이콘이 생겨요. 다음부터는 아이콘으로 여세요.
   설치가 끝나면 "내려받은 설치 폴더와 예전 zip을 지울까요?"라고 물어봐요. [예]를 누르면 정리돼요.
설치 위치: %LOCALAPPDATA%\NursingHelper  · 관리자 권한 필요 없음 · Windows 10/11 (앱 창은 Windows에 들어 있는 Edge로 열려요)

사용 방법
1. 주관적 자료: 대상자가 직접 한 말을 한 줄에 하나씩 적습니다.
2. 객관적 자료: V/S, 검사 결과, 관찰 내용, 이미 투여된 약물을 한 줄에 하나씩 적습니다.
   예) Fever(+)  /  NRS : 5/10점  /  WBC(20000)  /  데노간(+)
3. 의학적 진단(Dx)과 작성 날짜를 넣습니다.
4. '진단 추천 받기'를 누르면 자료에 맞는 간호진단이 체크됩니다. 목록 위쪽이 우선순위가 높습니다.
5. 진단을 눌러 '원인(관련 요인)'을 대상자에 맞게 고칩니다.
   - 방식 1: (원인)과 관련된 (진단명)
   - 방식 2: '원인의 원인'까지 적으면 (원인의 원인)으로 인한 (원인)과 관련된 (진단명)
6. '틀 만들기'를 누릅니다. 주황색 글자는 실습하면서 채웁니다.
7. 결과에서 제출 양식 / B4 워크북 / 기본을 고르고, '한글 저장'(.hwpx) · 'Word 저장' · 'PDF·인쇄' · '복사'를 합니다.
   저장한 파일은 '다운로드' 폴더에 생겨요.
'예시 불러오기'를 누르면 급성 복막염 예시로 바로 확인할 수 있습니다.

AI로 다듬기 (선택)
- ChatGPT로 / Claude로: 구독 계정으로 무료(추가 비용 없음). 붙여넣기·복사 한 번씩 필요.
- 제미나이로 다듬기: 아래 API 키 방식.
- 자료에 맞게 목표 수치와 이론적 근거를 더 구체적으로 다듬어 줍니다.
- 처음 누르면 API 키를 묻습니다. aistudio.google.com → Get API key 에서 무료로 발급받으세요.
- 키는 이 PC의 앱 창 안에만 저장됩니다. 코드나 GitHub에 들어가지 않습니다.
- 모델 이름은 '설정'에서 바꿀 수 있습니다 (기본: gemini-2.5-flash).
- 다듬은 결과가 마음에 안 들면 '되돌리기'를 누릅니다.
- 입력한 자료가 Google로 전송되므로 환자 이름·등록번호·생년월일 같은 개인정보는 넣지 마세요.
