간호과정 도우미 1.1.1

1.1 새 기능
- 애플 스타일 새 화면 (둥근 카드, 알약 버튼, 아이폰식 체크 목록)
- 'B4 워크북' 형식: 간호과정 별책 워크북 순서 그대로
  간호사정(주관적·객관적 자료, 자료조직, 간호문제) → 간호진단(단서묶음, 영역찾기, 진단명과 정의, 관련요인, 진술)
  → 간호계획(우선순위와 근거, 목표, 중재·이론적 근거) → 간호수행 및 평가 → 간호기록지(SOAPIE)
- 저장 → Word(.doc)를 고르면 B4 가로 표 양식으로 저장 (한글은 .html로 저장해서 열기)
- 진단명을 NANDA-I 2024–2026 기준으로 변경, 영역·과·별책 부록 8 페이지 표시
- 진단 추가: 비효과적 기도청결, 구강점막 통합성 손상, 아동 낙상의 위험 (총 14개)
- 우선순위 정렬: 위/아래 버튼, '자동 정렬'(ABC·매슬로우)
- 대상자 선택: 아동(보호자 포함) / 성인
- 실행 오류가 나면 오류 내용을 창에 바로 보여 줌

무엇을 하나요?
주관적·객관적 자료를 넣으면 간호과정 보고서의 큰 틀을 자동으로 만들어 줍니다.
■ 사정(주관적/객관적 자료) → ■ 진단 → ■ 계획(장기·단기목표, 진단적·치료적·교육적 계획 + 이론적 근거)
→ ■ 중재(계획을 '~하였다'로 바꾸고 날짜·시간 칸 생성) → ■ 평가(달성 / 부분적 달성 / 달성 못함)

설치
1. 압축을 풉니다.
2. NursingHelperSetup.exe를 실행합니다. (파란 경고창이 뜨면 '추가 정보' → '실행')
3. 바탕화면의 '간호과정 도우미'를 더블클릭합니다.
설치 위치: %LOCALAPPDATA%\NursingHelper  · 관리자 권한 필요 없음 · Windows 10/11

사용 방법
1. 주관적 자료: 대상자가 직접 한 말을 한 줄에 하나씩 적습니다.
2. 객관적 자료: V/S, 검사 결과, 관찰 내용, 이미 투여된 약물을 한 줄에 하나씩 적습니다.
   예) Fever(+)  /  NRS : 5/10점  /  WBC(20000)  /  데노간(+)
3. 의학적 진단(Dx)과 작성 날짜를 넣습니다.
4. '진단 추천'을 누르면 자료에 맞는 간호진단이 체크됩니다. 목록 위쪽이 우선순위가 높습니다.
5. 목록에서 진단을 클릭하고 '원인(관련 요인)'을 대상자에 맞게 고칩니다.
   - 방식 1: (원인)과 관련된 (진단명)
   - 방식 2: '원인의 원인'까지 적으면 (원인의 원인)으로 인한 (원인)과 관련된 (진단명)
6. '틀 만들기'(Ctrl+Enter)를 누릅니다. 주황색 칸(__:__, __/__)은 실습하면서 채웁니다.
7. 오른쪽 결과는 바로 고칠 수 있고, '복사' 또는 '저장'(Word .doc / .html / .rtf / .txt)을 합니다.
'예시 불러오기'를 누르면 급성 복막염 예시로 바로 확인할 수 있습니다.

제미나이로 다듬기 (선택)
- 자료에 맞게 목표 수치와 이론적 근거를 더 구체적으로 다듬어 줍니다.
- 처음 누르면 API 키를 묻습니다. aistudio.google.com → Get API key 에서 무료로 발급받으세요.
- 키는 이 PC의 Windows 계정으로 암호화해서 저장됩니다. 코드나 GitHub에 들어가지 않습니다.
- 모델 이름은 '설정'에서 바꿀 수 있습니다 (기본: gemini-2.5-flash).
- 다듬은 결과가 마음에 안 들면 '되돌리기'를 누릅니다.
- 입력한 자료가 Google로 전송되므로 환자 이름·등록번호·생년월일 같은 개인정보는 넣지 마세요.

들어 있는 간호진단 (14개 · NANDA-I 2024–2026)
급성 통증, 고체온, 감염의 위험, 불충분한 체액량, 과도한 불안, 비효과적 호흡양상, 비효과적 기도청결,
불충분한 영양섭취, 성인 낙상의 위험, 아동 낙상의 위험, 불충분한 건강지식, 비효과적 수면양상, 배변 장애, 구강점막 통합성 손상

주의
자동으로 만든 틀입니다. 이론적 근거와 수치는 반드시 전공 교재와 대상자 자료로 확인·수정하세요.

문제 해결
실행 실패 기록: %LOCALAPPDATA%\NursingHelper\runtime.log
제거: 바탕화면 바로가기와 %LOCALAPPDATA%\NursingHelper 폴더를 삭제합니다.
