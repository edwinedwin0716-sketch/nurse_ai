학습 정리 도우미 1.0

무엇을 하나요?
강의자료·필기 파일에서 형광펜, 색 글씨·굵은 글씨, 펜 필기(밑줄·동그라미·체크)를 찾아
아래 형식의 학습 자료를 만들어 줘요. 인터넷·API 없이 기기 안에서만 처리해요.
  표지 → 요점정리(단원 제목 띠 · 소제목 · 핵심어 굵게 · 형광펜 부분 노란색 · 수치 박스)
  → 핵심 수치 모아보기 → 지식확인 문제(유형별 5지선다·OX) → 정답표(번호 | 정답 | 해설)
  → 표시한 문항 다시 보기(원본 문제 중 펜으로 체크·동그라미·X 한 문항)

올릴 수 있는 파일
- PDF: 굿노트·삼성노트·노타빌리티 필기 PDF, 형광펜 칠한 강의자료 PDF (글자를 선택할 수 있는 PDF)
- PowerPoint .pptx · Word .docx · 한글 .hwpx
- 한글 .hwp(옛 형식)는 한글에서 [다른 이름으로 저장 → HWPX 또는 PDF] 후 올려 주세요.
- 스캔·사진 PDF(글자 정보 없음)는 읽을 수 없어요.

컴퓨터
1. 학습정리도우미.html 을 더블클릭 (크롬 또는 엣지로 열려요)
2. 파일 올리기 → 문제 수 선택 → 정리 시작
3. Word로 저장 / 웹 페이지로 저장 / PDF·인쇄

휴대폰 (안드로이드)
1. StudyHelper.apk 설치 (출처를 알 수 없는 앱 허용 → 설치)
2. 앱에서 '파일 올리기' 또는 삼성노트·굿노트에서 [공유 → 학습 정리 도우미]
3. 정리 시작 → Word로 저장(다운로드 폴더) / PDF·인쇄(PDF로 저장 가능)

사례기반 문제 · 문장형 요약
AI가 있어야 만들 수 있어요. 'ChatGPT로 사례문제 만들기' 버튼을 누르면 정리한 내용이 복사되고
ChatGPT(또는 Claude) 앱이 열려요. 붙여넣고 보내면 사례 문제와 정답표를 만들어 줘요. 구독 그대로, API 키 필요 없음.

알아 두기
- 요점정리는 원문 문장을 그대로 골라 정리해요(새로 쓰지는 않아요).
- 문제의 오답 보기는 다른 강조 용어나 수치를 바꿔서 만들어요. 문제와 해설은 교재로 꼭 확인하세요.
- 손글씨 내용 자체는 읽지 못해요. 필기한 줄의 인쇄된 문장을 중요 내용으로 잡아요.
- 쪽수가 많으면(100쪽 이상) 휴대폰에서 몇 분 걸릴 수 있어요.
