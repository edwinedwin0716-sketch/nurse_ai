플래시카드 학습 2.0

무엇을 하나요?
강의자료·필기 파일에서 형광펜, 색 글씨·굵은 글씨, 펜 필기(밑줄·동그라미·체크)를 찾아
플래시카드로 만들어 외우게 해 줘요. 인터넷·API 없이 기기 안에서만 처리해요.

카드 종류
- 빈칸: 강조한 말을 가린 문장 → 뒤집으면 정답과 원문
- 수치: 숫자(24~28주, 140mg/dL 등)를 가린 문장
- 용어: "전자간증" → 뒤집으면 뜻("전자간증은 …")
- 문제: 5지선다·OX (보기를 누르면 바로 채점)
- 표시한 문항: 원본 문제 중 펜으로 체크·동그라미·X 한 문항

학습 방법
1. 카드를 누르면 뒤집혀요. (PC: Space)
2. 모름 / 애매 / 알아요 를 고르세요. (PC: 1·2·3, 휴대폰: 왼쪽으로 밀면 모름, 오른쪽으로 밀면 알아요)
   - 모름: 몇 장 뒤에 다시 나와요
   - 애매: 이번 학습 끝에 다시 나와요
   - 알아요: 1일 → 3일 → 7일 → 14일 → 30일 뒤에 복습하도록 미뤄져요
3. 위쪽 칩으로 단원(1. 고혈압 등)만 골라 볼 수 있어요.
4. 오늘 학습 / 틀린 카드 / 전체 섞기 중에 고를 수 있어요.
진도는 기기에 자동 저장돼요.

같은 제목은 하나로
원본에서 "1. 고혈압"이 뒤에 또 나오면(다음 쪽 머리글, "(계속)" 등) 새 제목을 만들지 않고
처음 나온 "1. 고혈압" 아래로 합쳐요. 큰 제목(○장·○절)이 쪽마다 반복돼도 하나로 합쳐요.

카드 묶음 메뉴 (⋯)
- 학습지로 저장(Word) · 학습지 PDF·인쇄: 요점정리·핵심 수치·문제·정답표 형식
- ChatGPT로 사례문제 만들기: 정리한 내용을 복사해 ChatGPT 앱에 붙여넣기 (구독 그대로, API 키 필요 없음)
- 진도 초기화 · 삭제

올릴 수 있는 파일
- PDF(굿노트·삼성노트·노타빌리티 필기 포함, 글자를 선택할 수 있는 PDF) · PPTX · DOCX · HWPX
- .hwp는 한글에서 HWPX 또는 PDF로 저장해서 올려 주세요. 스캔·사진 PDF는 읽을 수 없어요.
